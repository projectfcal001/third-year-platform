1.2) ⚠️ القواعد الأساسية
كل مادة في مجلد منفصل داخل datenew/{slug}/

ملف المادة: datenew/{slug}/{slug}.js

ملف السكاشن: datenew/{slug}/sections-{slug}.json (بيتلقط تلقائيًا)

اسم مجلد المادة = اسم الـ slug بالظبط

لو مش محدد sectionsFile صراحةً → التطبيق يشتق المسار تلقائيًا

1.3) 📌 المفاهيم الأساسية
المفهوم	معناه	مثال
المادة	ملف JS في datenew/{slug}/	computer-networks
المحاضرة	كائن داخل lectures[]	"مقدمة الشبكات"
السكشن	كائن داخل sections[] في JSON	"سكشن A — م. أحمد"
المعيد	شخص، وله instructorId ثابت	inst-ahmed
المجموعة	اسم المجموعة تحت المعيد	"سكشن A"
الفصل (Chapter)	تجميع لمجموعة محاضرات	"الفصل الأول"
1.4) ⚠️ قاعدة ذهبية

📘 الجزء 5: إضافة الأسئلة (MCQ + مقالي)
5.1) 🅰️ سؤال اختيار من متعدد (MCQ)
js
{
  q: "ما هو الـ Array؟",
  options: [
    "مصفوفة ثابتة الحجم",
    "مصفوفة ديناميكية",
    "نوع من المتغيرات",
    "كل ما سبق"
  ],
  correct: 0,                       // ← الإجابة الصحيحة (يبدأ من 0)
  translation: "What is an Array?",  // (اختياري)
  explanation: "الـ Array مصفوفة..."  // (اختياري)
}
📌 قواعد مهمة
correct يبدأ من 0 (مش 1):

0 = الإجابة الأولى

1 = الإجابة التانية

2 = الإجابة التالتة

3 = الإجابة الرابعة

عدد options لازم يكون 2 على الأقل (يُفضّل 4).

correct لازم يكون بين 0 و options.length - 1.

5.2) 🅱️ سؤال مقالي (Essay)
js
{
  type: "essay",                    // ← إجباري
  q: "اشرح الفرق بين Stack و Queue",
  answer: `الإجابة النموذجية الكاملة...
  
يمكن استخدام أسطر متعددة.

ويتم عرضها في صندوق خاص.`,
  tags: ["مهم", "فصل 2"],            // (اختياري)
  ref: "المرجع: الكتاب ص 45",        // (اختياري)
  translation: "Explain...",         // (اختياري)
  explanation: "السبب..."            // (اختياري)
}
📌 إزاي بيتحسب في الدرجة؟
الأسئلة المقالية مش بتتحسب في نسبة الدرجة.

بتظهر كـ 📝 مقالي: X في تفاصيل النتيجة.

لو كل الامتحان مقالي: الاختبار ده كله أسئلة مقالية — التصحيح يدوي.

5.3) 🌐 إضافة الترجمة والشرح (اختياري)
أي سؤال (MCQ أو مقالي) يقدر يكون عنده:

js
{
  q: "...",
  options: [...],
  correct: 0,

An array is a...`,

- السبب الأول
- السبب الثاني`
}

📘 الجزء 12: الأخطاء الشائعة وكيفية تجنبها
❌ خطأ 1: نسيان الفاصلة
js
lectures: [
  { /* محاضرة 1 */ }     ← مفيش فاصلة
  { /* محاضرة 2 */ }     ← ❌ هيكسر
]
الحل: فاصلة (,) بعد كل عنصر ما عدا الأخير.

❌ خطأ 2: تكرار id
js
{ id: "net-lecture-04", t: "..." }
{ id: "net-lecture-04", t: "..." }   // ❌ نفس الـ ID
الحل: كل id فريد.

❌ خطأ 3: عدم تطابق lectureId
text
ملف المحاضرة: { id: "net-lecture-04" }
ملف السكشن:   { "lectureId": "net-lecture-05" }   // ❌ مش هيظهر
الحل: اتأكد lectureId = id المحاضرة بالظبط.

❌ خطأ 4: subject غير متطابق
text
subjects-index.js: { slug: "computer-networks" }
sections.json:     { "subject": "computer-network" }  // ❌
الحل: انسخ slug من subjects-index.js حرفيًا.

❌ خطأ 5: المعيد نفسه بـ IDs مختلفة
json
{ "instructorId": "inst-ahmed" }
{ "instructorId": "ahmed-1" }    // ❌ هيظهر كشخصين
الحل: نفس المعيد = نفس instructorId دائمًا.

❌ خطأ 6: instructorId متطابق لمعيدين مختلفين
json
{ "instructorId": "inst-001", "instructorName": "م. أحمد" }
{ "instructorId": "inst-001", "instructorName": "م. سارة" }  // ❌
الحل: كل معيد = instructorId خاص به.

❌ خطأ 7: JSON غير صالح
json
{ "sections": [ { "id": "x", } ] }   // ❌ فاصلة قبل }
الحل: استخدم JSONLint للتأكد.

❌ خطأ 8: أسئلة بدون correct
js
{ q: "السؤال؟", options: ["أ", "ب"] }   // ❌ نسيت correct
الحل: MCQ لازم correct: <index>.

❌ خطأ 9: correct أكبر من عدد options
js
{ options: ["أ", "ب"], correct: 5 }   // ❌ index 5 مش موجود
الحل: correct بين 0 و options.length - 1.

❌ خطأ 10: روابط بـ http:// بدل https://
json
{ "recording": "http://example.com/video" }   // ❌
الحل: كل الروابط الخارجية لازم https://.

❌ خطأ 11: ملف المادة في مسار غلط
text
subjects-index: { file: "computer-networks.js" }   // ❌
الحل: file: "datenew/computer-networks/computer-networks.js"

❌ خطأ 12: ملف السكاشن في مسار غلط
المتوقع تلقائيًا: datenew/{slug}/sections-{slug}.json
الحل: اما تلتزم بالمسار التلقائي، أو تحدد sectionsFile صراحةً.
