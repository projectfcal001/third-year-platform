1.3) ⚠️ القواعد الأساسية
- المادة المشتركة (زي software-engineering) ليها نسخة واحدة بس في datenew/subjects/ — وكل قسم بيشاور عليها من subjects-index.js بتاعه.
- لو عدّلت محاضرة في مادة مشتركة → التعديل بيظهر في كل الأقسام اللي فيها المادة دي (ده المطلوب).
- ملف المادة: datenew/subjects/{slug}/{slug}.js
- ملف السكاشن: datenew/subjects/{slug}/sections-{slug}.json
- اسم مجلد المادة = الـ slug بالظبط (حروف إنجليزي صغيرة وشرطات).
- تقدّم الطالب (إجابات/علامات/نتائج) متخزّن بـ اسم المادة → المادة المشتركة بتحافظ على تقدّمها لو الطالب غيّر القسم.
- ⚠️ مسار السكاشن التلقائي في app.js لسه قديم (datenew/{slug}/...) — عشان كده لازم تكتب sectionsFile صراحةً في كل مادة (شوف الجزء 19).

📘 الجزء 2: نظام الأقسام (جديد)
2.1) 🔄 إزاي بيشتغل؟
1) index.html بيحمّل datenew/departments.js (تعريف الأقسام).
2) app.js بيقرأ القسم المختار من:
   - ?dept=ai في الرابط (رابط مشاركة) — بيتحفظ تلقائيًا، أو
   - localStorage تحت المفتاح dept_v1.
3) أول زيارة (مفيش قسم محفوظ) → تظهر نافذة 🎓 "اختار القسم بتاعك" ومش بتتقفل.
4) بعد الاختيار بيتحمّل ملف الفهرس بتاع القسم بس (مثلًا datenew/ai/subjects-index.js) — الأقسام التانية ما بتتحمّلش.
5) زر 🎓 في شريط المواد بيسمح بتغيير القسم (بيحفظ الاختيار ويعمل reload نظيف).

2.2) 📝 شكل datenew/departments.js
js
var DEPARTMENTS = [
  { id: "cs", name: "علوم الحاسب",        en: "Computer Science",       icon: "💻", index: "datenew/cs/subjects-index.js", active: true },
  { id: "is", name: "نظم المعلومات",       en: "Information Systems",   icon: "🗄️", index: "datenew/is/subjects-index.js", active: true },
  { id: "se", name: "هندسة البرمجيات",     en: "Software Engineering",   icon: "🏗️", index: "datenew/se/subjects-index.js", active: true },
  { id: "ai", name: "الذكاء الاصطناعي",    en: "Artificial Intelligence", icon: "🤖", index: "datenew/ai/subjects-index.js", active: true }
];
📌 الحقول: id (إنجليزي صغير — بيستخدم في ?dept=) / name (يظهر للطالب) / en (تحت الاسم) / icon / index (مسار فهرس المواد) / active (false = القسم مخفي).
⚠️ الأسماء أعلاه أمثلة للشكل — راجع الملف الفعلي عندك للقيم الحقيقية.

3.2) 🔗 ربط مادة موجودة بقسم تاني
مثال: عايز hci تظهر في قسم cs كمان:
1) افتح datenew/cs/subjects-index.js
2) انسخ object مادة hci من datenew/ai/subjects-index.js حرفيًا (نفس slug/file/sectionsFile)
3) ضيفه في المكان اللي عايز ترتيبه
4) خلاص — مفيش نسخ ملفات.

3.3) 🏫 إضافة قسم جديد
1) أنشئ datenew/{id}/subjects-index.js بـ var SUBJECTS_INDEX = [ ... ];
2) ضيف object القسم في datenew/departments.js (id / name / en / icon / index / active)
3) اختبر ?dept={id}.
4) حدّث CODEOWNERS لو فيه مسؤول للقسم الجديد.

3.4) 📌 ملاحظات مهمة
- slug لازم يكون حروف إنجليزي صغيرة بدون مسافات.
- active: false = المادة مخفية عن الطلاب (بس تفضل قابلة للفتح من الرابط المباشر).
- sectionTitle (اختياري) = عنوان قسم السكشن جوه المحاضرة.
- 📂 توصية لتنظيم الملفات جوه المادة:
    lectures/   ← ملفات المحاضرات + الملخصات
    questions/  ← ملفات الأسئلة + الامتحانات + بنوك الأسئلة PDF
    sections/   ← 🆕 ملفات السكاشن: ملف السكشن + التمارين + الحل + الواجب
                  (اختياري: فولدر فرعي لكل معيد، مثلًا sections/inst-ahmed/)
  (التسمية نفسها مش مفروضة من الكود — الكود بيقرأ المسار اللي تكتبه — بس خلّيها ثابتة، وراجع NAMING.md.)

📘 الجزء 6: إضافة الأسئلة (MCQ + مقالي)
6.1) 🅰️ سؤال اختيار من متعدد (MCQ)
js
{
  q: "ما هو الـ Array؟",
  options: [
    "مصفوفة ثابتة الحجم",
    "مصفوفة ديناميكية",
    "نوع من المتغيرات",
    "كل ما سبق"
  ],
  correct: 0,                       // ← الإجابة الصحيحة (يبدأ من 0)
  translation: "What is an Array?",  // (اختياري)
  explanation: "الـ Array مصفوفة..."  // (اختياري)
}
📌 قواعد مهمة
correct يبدأ من 0 (مش 1): 0 = الأولى / 1 = التانية / 2 = التالتة / 3 = الرابعة
عدد options لازم يكون 2 على الأقل (يُفضّل 4).
correct لازم يكون بين 0 و options.length - 1.

6.2) 🅱️ سؤال مقالي (Essay)
js
{
  type: "essay",                    // ← إجباري
  q: "اشرح الفرق بين Stack و Queue",
  answer: `الإجابة النموذجية الكاملة...

يمكن استخدام أسطر متعددة.`,
  tags: ["مهم", "فصل 2"],            // (اختياري)
  ref: "المرجع: الكتاب ص 45",        // (اختياري)
  translation: "Explain...",         // (اختياري)
  explanation: "السبب..."            // (اختياري)
}
📌 إزاي بيتحسب في الدرجة؟
الأسئلة المقالية مش بتتحسب في نسبة الدرجة، وبتظهر كـ 📝 مقالي: X في تفاصيل النتيجة.
لو كل الامتحان مقالي: التصحيح يدوي.

6.3) 🌐 الترجمة والشرح (اختياري لأي سؤال)
🌐 ترجمة السؤال — زر قابل للطي (لوحة رمادية فاتحة)
💡 لماذا هذه الإجابة؟ — زر قابل للطي (لوحة زرقاء فاتحة)
