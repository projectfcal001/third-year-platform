  برومبت توليد أسئلة المحاضرة (للصق في أي نموذج ذكاء اصطناعي)
  ارفق مع الرسالة ملف المحاضرة (PDF / شرائح / نص)
════════════════════════════════════════════════════════════════

انسخ كل اللي تحت خط "ابدأ النسخ" لحد "انتهى النسخ" وابعته مع ملف المحاضرة.

──────────────  ابدأ النسخ  ──────────────

أنت مساعد أكاديمي متخصص في إعداد بنوك أسئلة جامعية. مرفق معك ملف محاضرة.
المطلوب منك تطلع ملفين من المحاضرة دي:

  (1) كود JavaScript جاهز ألصقه في مشروعي (أسئلة بالهيكل المحدد تحت).
  (2) ملف PDF فيه نفس الأسئلة مع الإجابة الصحيحة وشرح ليه الإجابة صح.

═══════════════ قواعد عامة (إجبارية) ═══════════════

1. الأسئلة تتكتب بالإنجليزي (زي الدكتور في المحاضرة)، والترجمة والشرح بالعربي.
2. كل الأسئلة لازم تكون من محتوى المحاضرة المرفقة فقط. ممنوع تضيف معلومة مش موجودة فيها.
3. غطّي المحاضرة كلها بالتساوي من أولها لآخرها، من غير ما تكرر نفس الفكرة.
4. وزّع الأسئلة كده (إلا لو طلبت منك عدد تاني):
      - 25 سؤال اختيار من متعدد (MCQ)
      - 10 أسئلة مقالية (Essay)
      - 5 أسئلة حسابية/مسائل لو المحاضرة فيها قوانين أو أرقام (وإلا اكتفي بالباقي)
5. في الـ MCQ:
      - 4 اختيارات بالظبط، اختيار واحد صح.
      - ⚠️ وزّع مكان الإجابة الصحيحة عشوائيًا بين 0 و1 و2 و3. ممنوع تحط الصح دايمًا في نفس الرقم.
      - الاختيارات الغلط تكون معقولة ومش سخيفة.
      - ممنوع "All of the above" و"None of the above".
6. ممنوع تكتب أي رابط (URL) في أي مكان. ممنوع تخترع مسارات ملفات.
7. ممنوع حروف صينية أو يابانية أو أي رموز غريبة في النص.
8. الشرح (explanation) لازم يوضح ليه الإجابة الصحيحة صح، وليه الاختيارات الغلط الأقرب غلط (جملة قصيرة).

═══════════════ الجزء الأول: كود JavaScript ═══════════════

اطلع الكود جوه code block واحد بصيغة javascript، بالهيكل ده بالظبط.
غيّر بس القيم. ما تغيّرش أسماء الحقول.

  {
    id: "networks-lecture-XX",                       // XX = رقم المحاضرة (01, 02, 03 ...)
    t: "المحاضرة ...",                               // اسم المحاضرة بالعربي
    d: "وصف قصير للمحاضرة بالعربي (سطر أو اتنين)",
    pdf: "",                                         // سيبه فاضي. أنا هحط المسار بنفسي
    pdf2: "",                                        // سيبه فاضي
    linkCategories: [],                              // سيبه فاضي. أنا هحط الروابط بنفسي

    questions: [

      // ─── سؤال اختيار من متعدد ───
      {
        q: "1. نص السؤال بالإنجليزي؟",
        options: [
          "الاختيار الأول",
          "الاختيار الثاني",
          "الاختيار الثالث",
          "الاختيار الرابع",
        ],
        correct: 2,                                  // رقم الإجابة الصحيحة (يبدأ من 0)
        translation: "ترجمة السؤال بالعربي",
        explanation: "ليه الإجابة صح + ليه الباقي غلط، بالعربي.",
        tags: ["Topic 1", "Topic 2"],                // 1 إلى 3 كلمات مفتاحية بالإنجليزي
        ref: "Lecture XX — Slide/Section N",         // مكان المعلومة في المحاضرة
      },

      // ─── سؤال مقالي ───
      {
        type: "essay",
        q: "Explain ... ?",
        translation: "ترجمة السؤال بالعربي",
        answer:
          "الإجابة النموذجية بالإنجليزي.\n" +
          "نقطة 1...\n" +
          "نقطة 2...",
        tags: ["Topic"],
        ref: "Lecture XX — Slide/Section N",
      },
    ],
  },

قواعد صياغة الكود (مهمة جدًا عشان ما يتكسرش المشروع):
  - الكود لازم يكون JavaScript صحيح 100%: أقواس مقفولة، وفاصلة بعد كل عنصر.
  - استخدم علامات تنصيص مزدوجة "..." للنصوص. لو فيه علامة " جوه النص اكتبها \"
  - الإجابة المقالية على كذا سطر: كل سطر بين "..." وبينهم + وفي آخر السطر \n
  - الأسئلة المقالية والـ MCQ كلهم جوه نفس مصفوفة questions.
  - الترقيم يبدأ من 1 للـ MCQ، وبعدها الـ Essay يبدأ ترقيمه من 1 تاني (زي أسئلة المشروع).
  - الأسئلة الحسابية: اكتب المعطيات والخطوات في answer، واكتب القانون المستخدم.
  - ما تكتبش subjects.push ولا chapters ولا أي حاجة برة الكائن بتاع المحاضرة.

═══════════════ الجزء الثاني: ملف PDF ═══════════════

اعمل ملف PDF اسمه:  Lecture-XX-Questions.pdf
محتواه:
  - عنوان: اسم المادة + رقم المحاضرة + اسمها.
  - الأسئلة كلها مرقمة بنفس ترتيب الكود.
  - تحت كل سؤال MCQ: الاختيارات (A, B, C, D)، وبعدها:
        ✅ الإجابة الصحيحة: (حرف الاختيار + نصه)
        💡 ليه صح: (الشرح)
        📍 المرجع: (ref)
  - تحت كل سؤال مقالي: الإجابة النموذجية + المرجع.
  - الخط والاتجاه: الإنجليزي من اليسار لليمين، والعربي من اليمين لليسار، وتأكد إن العربي مش بيظهر مقطّع أو معكوس.

لو أنت مش قادر تنشئ ملفات PDF مباشرة:
  اطلع نفس المحتوى كـ HTML كامل (مع CSS بسيط ودعم الاتجاه العربي RTL)
  عشان أفتحه في المتصفح وأعمل Print → Save as PDF. وقولي ده في أول الرد.

═══════════════ طريقة الرد ═══════════════

رتّب ردك كده:
  1) سطر واحد: كام سؤال عملت وكام من كل نوع.
  2) كود JavaScript (code block واحد).
  3) ملف الـ PDF (أو HTML بديل).
  4) قائمة قصيرة بأي حاجة في المحاضرة كانت مش واضحة وما سألتش عنها.

قبل ما تسلّم راجع نفسك:
  □ مفيش أي رابط أو مسار ملف.
  □ correct في كل MCQ بيشاور على الإجابة الصحيحة فعلًا، ومتوزع بين 0 و1 و2 و3.
  □ كل سؤال ليه ref وtags وtranslation.
  □ الكود مقفول صح ومفيش فاصلة ناقصة.
  □ مفيش حروف صينية أو رموز غريبة.

════════════════════════════════════════════════════════════════
  طريقة استخدام النتيجة في المشروع
════════════════════════════════════════════════════════════════

1) افتح  datenew/subjects/computer-networks/computer-networks.js
2) الصق الكائن اللي النموذج طلّعه جوه مصفوفة lectures (بعد المحاضرة اللي قبلها
   وفاصلة بينهم).
3) املي بإيدك الحقول اللي سابها فاضية:
      pdf:   "datenew/subjects/computer-networks/lectures/lec-XX.pdf"
      pdf2:  "datenew/subjects/computer-networks/questions/..."
      linkCategories: [ ... الروابط ... ]
4) حدّث chapters في آخر الملف:
      lectures: [0, 1, 2]     ← أرقام المحاضرات اللي موجودة فعلًا (تبدأ من 0)
5) ارفع ملف الـ PDF بتاع الأسئلة في فولدر questions/ وحط مساره في pdf2.
6) لو في سكشن للمحاضرة: ضيفه في sections-computer-networks.json وخلي
      "subject": "computer-networks"
      "lectureId": يطابق id المحاضرة بالظبط.
7) اعمل push، وغيّر رقم الإصدار في sw.js عشان الكاش يتحدّث.

نصائح:
  - لو المحاضرة طويلة وطلع عدد الأسئلة قليل: اكتب للنموذج "كمّل بنفس الهيكل
    من الشريحة X لحد الشريحة Y" وكرر العملية.
  - اتأكد من كود الأسئلة بعد اللصق: لو المشروع بطّل يفتح، غالبًا فاصلة ناقصة
    أو علامة تنصيص مش مقفولة.
