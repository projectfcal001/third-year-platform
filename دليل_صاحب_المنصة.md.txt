# دليل صاحب المنصة — إزاي تضيف محتوى

> الدليل ده مبني على قراءة كود `app.js` الحالي. لو في حقل في ملفات المواد بتاعتك شكله مختلف عن اللي هنا، اتبعي الشكل الموجود في ملفاتك (انسخي مدخل موجود وعدّلي عليه).

## 1) هيكل الملفات

```
index.html, app.js
datenew/
  departments.js                  ← قائمة الأقسام الأربعة
  cs/subjects-index.js            ← فهرس مواد علوم الحاسب
  is/subjects-index.js            ← فهرس مواد نظم المعلومات
  se/subjects-index.js            ← فهرس مواد هندسة البرمجيات
  ai/subjects-index.js            ← فهرس مواد الذكاء الاصطناعي
  <slug>/<slug>.js                ← بيانات كل مادة (زي ما هي)
  <slug>/sections-<slug>.json     ← سكاشن كل مادة (زي ما هي)
```

- **الجدول وملخص التقدم** مشتركين في كل الأقسام (زرارهم ظاهر في كل قسم).
- **ملخص التقدم** بيعرض مواد القسم المختار بس (لأنه بيقرأ من فهرس القسم).
- اختيار القسم بيتحفظ في `localStorage` (المفتاح `dept_v1`)، وفهرس القسم بيتحمّل بعد الاختيار بس.
- الطالب يغيّر قسمه من زرار **"تغيير القسم ⇄"** أول زرار في شريط المواد.
- رابط مشاركة بقسم معين: `https://موقعك/?dept=ai` (بيتحفظ كاختيار للي يفتحه).

## 2) إضافة / إخفاء قسم
افتحي `datenew/departments.js`: أضيفي سطر جديد (`id` و`name` و`en` و`icon` و`index`) واعملي ملف الفهرس بتاعه. لإخفاء قسم حطي `active: false`.

## 3) إضافة مادة لقسم
1. اعملي ملف بيانات المادة `datenew/<slug>/<slug>.js` (انسخي مادة موجودة وعدّلي).
2. أضيفي مدخل في `datenew/<قسم>/subjects-index.js`:

```js
{ name:"اسم المادة", en:"Subject Name", icon:"📚", slug:"subject-slug", file:"datenew/subject-slug/subject-slug.js" }
```

**مادة مشتركة بين قسمين:** حطي نفس المدخل بالظبط (نفس `slug` ونفس `file`) في فهرس الاتنين — المحتوى والسكاشن وتقدم الطالب بيتشاركوا.

**مادتين بنفس الاسم لكن محتوى مختلف في قسمين:** لازم الـ `name` يكون مختلف (مثلًا "Software Engineering (AI)") وكمان `slug` و`file` مختلفين، لأن تقدم الطالب (الإجابات والدرجات) متخزن باسم المادة `name` — لو الاسم واحد والمحتوى مختلف التقدم هيتلخبط.

## 4) إضافة محاضرة
جوه ملف المادة، في مصفوفة `lectures` أضيفي عنصر:

```js
{
  t: "المحاضرة 5 — عنوان المحاضرة",   // العنوان (ومنه بيتولّد الـ id لو مفيش id)
  d: "وصف قصير",
  id: "lec-05",                      // اختياري لكن مفضّل ثابت (بيتربط بالسكاشن والروابط)
  pdf: "https://....pdf",            // ملف المحاضرة  (pdf2 لو موجود بياخد أولوية)
  links: [ { t:"🎥 تسجيل الفيديو", d:"...", url:"https://..." } ],
  chapter: "الفصل الأول",            // اختياري: تجميع المحاضرة تحت فصل
  summary: { pdf:"https://....pdf", text:"نص الملخص" },  // اختياري — بيظهر لو فيه بيانات فعلية
  sectionTitle: "🧩 السكشن",         // اختياري: عنوان زرار السكشن للمحاضرة دي
  questions: [ /* شوف الخطوة 5 */ ]
}
```

**الفصول بشكل منظّم:** ممكن بدل `chapter` في كل محاضرة تعملي في المادة `chapters: [ { t:"الفصل الأول", lectures:[0,1,2] } ]` (أرقام أو `id` المحاضرات).

## 5) إضافة أسئلة (جوه `questions` بتاعة المحاضرة)

اختيار من متعدد:
```js
{ q:"نص السؤال؟", options:["أ","ب","ج","د"], correct:1,   // correct = رقم الإجابة الصح (يبدأ من 0)
  explanation:"شرح الإجابة", translation:"ترجمة السؤال (اختياري)", tags:["tag"], ref:"المرجع" }
```
مقالي:
```js
{ type:"essay", q:"نص السؤال؟", answer:"الإجابة النموذجية", tags:["tag"], ref:"المرجع" }
```
> الميدتيرم والفاينال وبنوك الأسئلة (`midterms` / `finals` / `testBanks`): انسخي مدخل موجود في ملف مادتك وعدّلي عليه — بنك الأسئلة بيشاور على المحاضرات بأرقامها: `lectures:[0,1,2]`.

## 6) إضافة سكشن
في `datenew/<slug>/sections-<slug>.json`:

```json
{
  "sections": [
    {
      "subject": "subject-slug",
      "lectureId": "lec-05",
      "instructorId": "dr-ahmed",
      "instructorName": "د. أحمد",
      "groupName": "جروب 1",
      "status": "available",
      "materials": {
        "file":      "https://....pdf",
        "exercises": "https://....pdf",
        "solution":  "https://....pdf",
        "recording": "https://...",
        "extraLinks": [ { "label":"مصدر", "url":"https://..." } ]
      },
      "extraFiles": [ { "label":"ملف إضافي", "url":"https://....pdf", "type":"PDF" } ],
      "notes": "ملاحظة اختيارية"
    }
  ]
}
```
- الحقول اللي الكود بيتحقق منها: `subject` (= الـ slug) و`lecture` (= عنوان المحاضرة `t` بالظبط) **أو** `lectureId` (= `id` المحاضرة)، و`instructorId` و`instructorName`.
- `status`: `available` (متاح) / `soon` (قريبًا) / `unavailable` (غير متاح).
- زرار "السكشن" بيظهر في المحاضرة بس لو ليها سكاشن في الملف.

## 7) بعد أي تعديل
- ارفعي الملفات الجديدة/المعدلة على Vercel.
- لو الـ Service Worker (`sw.js`) بيعمل cache لملفات معينة، ضيفي فيه `datenew/departments.js` وملفات فهارس الأقسام الجديدة، وارفعي رقم نسخة الـ cache.
- جرّبي في تبويب خفي (Incognito) عشان تشوفي تجربة الطالب الجديد من أول اختيار القسم.
